PM status report generator

Turns a JIRA export and meeting notes into a draft program status report: an executive summary, a color-coded risk status per workstream, and the decisions leadership needs to make. I designed the report format, the status rules and the guardrails: facts only from the sources, "TBD" instead of invented owners or dates, JIRA keys cited on every row, and a TPM review before anything is sent.

Python · Anthropic API · JSON · HTML

RealSense Object Detection with Distance

Detects objects in real time with a RealSense™ depth camera and shows what each object is and how far away it is, in meters, along with its 3D position relative to the camera. Built on the official RealSense SDK Python examples: depth is aligned to the color image, a YOLO model finds the objects, and the distance comes from the median depth at each object’s center, so background and missing depth don’t skew it.

Python · pyrealsense2 (RealSense SDK 2.0) · Ultralytics YOLO · OpenCV · NumPy
